## 1. 项目概述

### 1.1 背景

做一个真正能上线使用的"云记事本"：用户注册登录后，可在任意设备的浏览器访问自己的笔记，数据保存在服务端，天然实现多端同步。

### 1.2 目标

- 满足个人日常记笔记需求：分类、打标签、快速搜索、回收站找回；
- 提供差异化功能：**日历视图**（按日期浏览当天创建的笔记）和**定时提醒**（设置 N 分钟/小时/天后提醒自己查看某篇笔记）；
- 可部署上线的完整 Web 应用（前后端分离）。

### 1.3 用户与使用场景

- 目标用户：个人用户，多账号注册使用；
- 使用场景：上班族记录待办与灵感、学生整理课程笔记、需要"定期回看某篇文档"的用户；
- 所有用户权限相同，初期不区分角色。

## 3. 功能需求

> 约定：P0 = 已实现（MVP 上线范围）；P1 = 重要，可放二期；P2 = 后续增强。

### 3.1 用户模块

**3.1.1 注册（P0）**

- 输入：用户名、邮箱、密码、邮箱验证码；
- 约束：用户名 3~20 位（字母/数字/下划线）且全局唯一；邮箱格式合法且全局唯一；密码 6~20 位；
- 获取验证码：后端通过 SMTP（QQ 邮箱）发送 6 位数字验证码，5 分钟有效，同邮箱 60 秒内限发一次；
- 只有验证码正确才能注册；注册成功后自动登录并创建"默认笔记本"；
- 密码使用 BCrypt 加密存储，禁止明文保存。

**3.1.2 登录（P0）**

- 输入：用户名、密码；
- 成功后签发 JWT Token，前端保存并携带访问受保护接口；
- 登录失败提示"用户名或密码错误"，不暴露具体原因。

**3.1.3 登出（P0）**

- 前端清除本地登录态（localStorage token + Pinia）。

**3.1.4 修改密码（P0）**

- 登录状态下，向当前账号邮箱发送验证码，输入验证码 + 新密码完成修改。

**3.1.5 找回密码（P0）**

- 输入注册邮箱 → 发送验证码 → 验证码正确后重设新密码。

**验收标准**

- 未登录访问业务接口返回 401；
- 用户 A 登录后无法访问/操作用户 B 的任何数据（全链路按 user_id 隔离）；
- 同一账号在多个浏览器/设备登录，看到的数据一致——即"同步"（本质是数据存服务端，登录即同步）；
- 多端同时编辑同一篇笔记时，以"最后保存"为准（Last-Write-Wins，P1 可升级为版本冲突提示）。

### 3.2 笔记本模块

- 新建笔记本：名称必填，同一用户下名称唯一（P0）；
- 笔记本列表：按创建时间倒序展示，含各笔记本笔记数（P0）；
- 侧边栏树形展开：点击笔记本展开/收起其下笔记列表（P0）；
- 重命名笔记本（P0）；
- 删除笔记本：**其下所有笔记一并移入回收站**，删除前弹窗二次确认（P0）；
- 系统为每个用户创建"默认笔记本"，不可重命名、不可删除（P0）；
- 笔记列表可按笔记本筛选（P0）。

### 3.3 笔记模块

- 新建笔记：可选择所属笔记本，默认放入"默认笔记本"；标题可为空（自动取正文纯文本前 50 字）（P0）；
- 编辑笔记：标题 + 正文，正文采用**富文本编辑器（wangEditor 5，所见即所得）**，存 HTML（P0）；
- 实时保存：内容或标题变化即自动保存（串行队列，切走/卸载前强制落盘），同时提供手动保存按钮；保存后提示"已保存"（P0）；
- 置顶：笔记可置顶，列表置顶优先展示（P0）；
- 图片：粘贴/上传截图自动上传至服务器磁盘，正文 HTML 中仅保存图片 URL（P0）；
- 导出：将正文导出为 `.md` 文件（前端 Turndown 将 HTML 转 Markdown）（P0）；
- 笔记列表：展示标题、所属笔记本、标签、置顶标记、最后编辑时间；支持按笔记本、按标签筛选，支持分页（P0）；
- 删除笔记：移入回收站（软删除），列表不再显示（P0）；
- 内容上限：单篇笔记 100 万字符内，超限时前端提示（P0）。

### 3.4 标签模块

- 新建标签：名称同一用户下唯一（P0）；
- 一篇笔记可添加多个标签，也可移除标签（P0）；
- 标签列表显示使用次数（P1）；
- 按标签筛选笔记列表（P0）；
- 删除标签：解除与所有笔记的关联（需二次确认）。

### 3.5 全文搜索

- 关键词搜索范围：**标题 + 正文纯文本**（P0）；
- 实现：正文为 HTML，故保存时派生 `content_text` 纯文本列，搜索用 `title LIKE '%kw%' OR content_text LIKE '%kw%'`；
- 可叠加筛选条件：所属笔记本、标签（P0）；
- 结果置顶优先、再按最后编辑时间倒序，分页展示，关键词在前端高亮（P0）；
- 实现方案（MVP）：纯文本列 LIKE；若数据量显著增长再评估引入 Elasticsearch（P2）。

### 3.6 回收站

- 回收站列出当前用户已删除的笔记，显示删除时间（P0）；
- 恢复笔记：回到原笔记本；**若原笔记本已被删除，则恢复到"默认笔记本"**（P0）；
- 彻底删除：二次确认后物理删除（含关联标签、图片文件），不可恢复（P0）；
- 清空回收站（P0）；
- 自动清空：回收站内超过 30 天的笔记由定时任务自动彻底删除（P0）；
- 删除笔记本时其下笔记进入回收站，同样支持以上操作（P0）。

### 3.7 日历视图

- 按月展示日历（P0）；
- **有笔记创建的日期变色标记**（圆点/背景高亮）（P0）；
- 点击某个日期 → 展示该日创建的笔记列表，点击笔记进入详情（P0）；
- 支持切换月份；当月有笔记的日期通过一次接口查询返回（P0）；
- 扩展（P1）：日历标记支持切换为"最后编辑日期"。

### 3.8 定时提醒（差异化功能）

- 在笔记上设置提醒：**N 分钟后 / N 小时后 / N 天后**（N 为 1~43200 的整数，从设置时刻起算）（P0）；
- 到期后生成一条**站内通知**：内容为笔记标题 +"该查看你的笔记了"，点击跳转到该笔记（P0）；
- 提醒状态：待提醒 / 已提醒 / 已取消；已提醒或已取消后可重新设置（P0）；
- 重复设置自动覆盖旧的待提醒；
- 取消提醒：删除该笔记或用户主动取消（P0）；
- 实现方案：Spring 定时任务每分钟扫描到期未提醒的记录，生成通知（P0）；
- 邮件通知：仅用于验证码（注册/找回/修改密码），不做"邮件提醒到点推送"。

### 3.9 通知中心

- 通知列表：未读在前、按时间倒序、分页（P0）；
- 顶部/侧边栏显示未读数量角标，登录后拉取，每 60 秒轮询（P0）；
- 单条标记已读、全部标记已读（P0）；
- 点击通知跳转到对应笔记（P0）。

### 3.10 图片管理

- 上传：粘贴截图 / 选择图片即上传后端，保存为独立磁盘文件（P0）；
- 正文只存图片 HTTP 访问 URL，**不使用 base64**（P0）；
- `note_image` 表维护笔记与图片关联，支持临时图片（笔记未创建完成 `note_id` 为空）（P0）；
- 生命周期：删除笔记彻底删除图片文件；孤儿图片由定时任务清理（P0）；
- 一张图片只归属一篇笔记，暂不做多笔记复用。

### 3.11 导出

- 将当前笔记导出为 `.md` 文件下载（P0）；
- 纯前端实现：Turndown 把正文 HTML 转为 Markdown，本地 Blob 下载，无后端接口。

### 3.12 实体关系总览（预览，详细设计见《02-数据库设计》）

- 用户 User（1）—（N）笔记本 Notebook
- 用户 User（1）—（N）笔记 Note
- 用户 User（1）—（N）笔记图片 NoteImage
- 笔记本 Notebook（1）—（N）笔记 Note
- 用户 User（1）—（N）标签 Tag；标签 Tag（N）—（N）笔记 Note（中间表 note_tag）
- 笔记 Note（1）—（N）图片 NoteImage
- 笔记 Note（1）—（1）提醒 Reminder（可独立成表）
- 用户 User（1）—（N）通知 Notification

## 4. 非功能需求

### 4.1 安全

- 密码 BCrypt 加密存储；
- 登录鉴权（JWT），所有业务接口按当前登录用户隔离数据；
- SQL 注入防护（MyBatis-Plus 参数化）；前端对渲染内容做 XSS 转义（列表高亮先转义用户内容）；
- 登录接口限流（如 5 次/分钟/账号，P1）；
- 生产环境禁止把密钥、SMTP 授权码、数据库密码提交到代码仓库（**当前授权码硬编码在配置中，上线前需迁出**）。

### 4.2 性能

- 单机、单用户笔记量 10 万以内时，核心接口响应 < 500ms；
- 列表接口统一分页（默认每页 20 条）；
- 为常用查询建立索引（user_id、notebook_id、创建时间等）。

### 4.3 数据与部署

- MySQL 8.x，utf8mb4，统一命名规范，提供初始化 SQL 脚本与增量变更脚本；
- 数据库定期备份策略（部署时配置）；
- 前后端分离部署：Vue 构建静态资源由 Nginx 托管，Nginx 反代 /api、/uploads 到后端；
- 后端打包为 Spring Boot 可执行 jar，配置外置（开发/生产环境分离）；
- Docker Compose 一键部署（P1，可选）。

## 5. 技术选型

### 后端

- JDK 17 + Spring Boot 3.3.x
- MyBatis-Plus 3.5.x + MySQL 8.0
- Lombok、spring-boot-starter-validation
- 鉴权：**JWT（jjwt 0.12）**，JwtInterceptor + UserContext（ThreadLocal）
- 邮件：spring-boot-starter-mail（QQ SMTP，smtps 465）
- 定时任务：Spring @Scheduled

### 前端

- Vue 3.4 + Vite 5 + TypeScript + Pinia + Vue Router + Element Plus + axios
- 富文本编辑器：**wangEditor 5**（@wangeditor/editor + @wangeditor/editor-for-vue）
- Markdown 导出：Turndown（HTML → Markdown）
- 日历组件：Element Plus 自带 el-calendar，通过自定义 cell 实现日期变色标记与点击事件
