## 4. 基础设施搭建顺序（M1 核心）

### 4.1 axios 实例 + 拦截器（`api/request.ts`）

- **请求拦截**：从 localStorage 取 token，自动加 `Authorization: Bearer <token>` 请求头
- **响应拦截**：
  - 业务成功（`body.code === 200`）→ 直接返回 `body.data`；
  - `status === 401` → 清除 localStorage token + **清空 Pinia userStore** 并跳转登录页（只清 localStorage 会导致路由守卫仍认为已登录而卡死）；
  - 其他非 200 → `ElMessage.error(message)`
- **Base URL**：`/api`（开发环境由 Vite 代理到 `http://localhost:8080`）

### 4.2 Pinia 用户 Store（`stores/user.ts`）

- 状态：`token`、`userInfo`（id / username / nickname / avatar）
- 初始化时从 localStorage 恢复 token
- 方法：
  - `login(username, password)` → 调接口 → 存 token + userInfo
  - `register(...)` → 同 login（注册成功即自动登录）
  - `fetchMe()` → 调 `GET /api/auth/me` 恢复 userInfo
  - `logout()` → 清 token + userInfo → 跳登录页

### 4.3 路由 + 导航守卫（`router/index.ts`）

- 路由表：
  - `/login` — 登录页（未登录可访问）
  - `/register` — 注册页（未登录可访问）
  - `/forgot-password` — 找回密码页（未登录可访问）
  - `/` — 主布局（需登录）
    - `/notes` — 笔记列表（默认首页）
    - `/notes/new` — 新建笔记
    - `/notes/:id` — 笔记编辑
    - `/trash` — 回收站
    - `/calendar` — 日历视图
    - `/notifications` — 通知中心
- 守卫逻辑：无 token → `/login`；有 token 但无 userInfo → 先调 `fetchMe()` 再放行

### 4.4 登录 / 注册 / 找回密码页

- 登录页：用户名 + 密码，成功后跳首页；
- 注册页：用户名 + 邮箱 + 验证码（`获取验证码` 按钮，60 秒倒计时）+ 密码 + 确认密码；
- 找回密码页：邮箱 + 验证码 + 新密码 + 确认新密码；
- 修改密码：在 `Layout.vue` 用户下拉菜单中弹窗完成（验证码发送到当前账号邮箱）。

**做完 M1 的标志**：可注册（验证码）→ 登录 → 刷新页面不丢登录态 → 登出后访问任何页面回登录页。

## 5. 核心模块（M2）

### 5.1 主布局（Layout.vue）

```
┌──────────┬──────────────────────────┐
│ Sidebar  │  Header（新建/铃铛/用户） │
│          ├──────────────────────────┤
│ 菜单      │                          │
│ 笔记本树   │  Main (<router-view>)    │
│ 标签列表  │                          │
└──────────┴──────────────────────────┘
```

- 左侧边栏：全部笔记 / 日历 / 回收站入口 + 笔记本树（点击展开/收起子笔记）+ 标签列表（右键删除）；
- 右上角：新建笔记按钮、通知铃铛（`el-badge` 未读角标）、用户下拉（修改密码 / 退出）；
- 未读角标：登录后拉取一次，之后每 60 秒轮询，组件卸载时**清除定时器**（避免泄漏）。

### 5.2 笔记编辑器（NoteEdit.vue，核心）

布局：

```
┌──────────────────────────────────────┐
│ 返回 | 标签选择        提醒/移动/导出/保存/删除 │
├──────────────────────────────────────┤
│ 标题输入框（首行，放大加粗，回车聚焦正文）   │
├──────────────────────────────────────┤
│  wangEditor 工具栏（v-if 编辑器就绪）   │
│  wangEditor 编辑区（所见即所得）        │
└──────────────────────────────────────┘
```

wangEditor 关键配置：

```ts
const toolbarConfig = {
  toolbarKeys: [
    'undo', 'redo', '|',
    'headerSelect', 'fontSize', 'fontFamily', '|',
    'bold', 'italic', 'underline', 'through', 'color', 'bgColor', '|',
    'blockquote', 'bulletedList', 'numberedList', 'todo', '|',
    'insertLink', 'uploadImage', 'insertTable', '|',
    'clearStyle'
  ]
}

const editorConfig = {
  placeholder: '请输入内容...',
  MENU_CONF: {
    uploadImage: {
      base64LimitSize: 0,   // 禁用 base64，全部走自定义上传
      async customUpload(file, insertFn) {
        const { url } = await uploadImage(file)
        insertFn(url, file.name, url)
      }
    }
  }
}
```

> 注意：工具栏要用 `v-if="editorRef"` 等编辑器就绪后再渲染，否则工具栏图标会出现禁用（禁止符号）；工具 key 用 `insertLink`/`insertTable` 而非 `link`/`table`。

实时保存实现思路（非防抖，输入即保存）：

```
内容/标题变化 → triggerAutoSave()
  → enqueueSave()：串行 Promise 队列（saveChain），同一时刻只排一个
  → 逐个调 PUT /api/notes/{id}
  → 用 editingNoteId 记录"正在编辑的笔记"，切换笔记时校验避免旧内容覆盖新笔记
切走 / 卸载前 → flushSave()：强制入队并 await 完成，确保不丢内容
```

> 新建笔记需先调 `POST /api/notes` 拿到 id，再 `router.replace` 到 `/notes/{id}`，后续编辑才能走 PUT。

### 5.3 笔记列表页（NoteList.vue）

- 顶部搜索框 + 笔记本筛选下拉 + 标签筛选 + 结果计数；
- 列表卡片：标题、正文预览、笔记本名、标签、置顶标记、最后编辑时间；
- 右键菜单：置顶/取消置顶、删除笔记；
- 分页用 `el-pagination`；
- **XSS 防护**：标题/预览用 `v-html` 渲染关键词高亮前，先对用户内容做 `escapeHtml` 转义，再包裹 `<mark>` 高亮；
- 时间展示：`time.replace('T',' ').replace(/\d{2}:\d{2}:\d{2}$/,'').trim()`。

**做完 M2 的标志**：新建笔记 → 富文本编辑 → 实时保存 → 切换笔记不丢内容 → 分页浏览。

## 6. 标签 + 搜索（M3）

### 6.1 标签管理

- 侧边栏显示标签列表；
- 笔记编辑时标签用 `el-select` multiple + `allow-create`：已有标签选 id，新输入走 `POST /api/tags` 创建后替换为 id；**创建失败（重名 409）时把该字符串从选中列表移除**并提示；
- 调 `saveNote` 的 `tagIds` 整体覆盖。

### 6.2 全文搜索

- 笔记列表页搜索框输入关键词 → 调接口叠加 `keyword` 参数（后端匹配标题 + `content_text`）；
- 搜索结果关键词高亮（先转义再高亮，防 XSS）。

## 8. 提醒 + 通知（M5）

### 8.1 提醒设置（NoteEdit.vue 内联弹窗）

- 编辑页"设置提醒"按钮 → 弹窗选 天/时/分，换算总分钟数；
- 调用 `POST /api/notes/{id}/reminder`，`unit = 'MINUTES'`、`value = 总分钟数`（1~43200，约 30 天）；
- 已设置提醒时按钮显示提醒时间（`remindAt.replace('T',' ')`），可取消。

### 8.2 通知中心（Notification.vue）

- 顶栏铃铛 + `el-badge` 未读角标（`stores/notification.ts` 维护，每 60 秒轮询）；
- 通知列表：未读在前、时间倒序、分页；
- 点击通知跳转笔记并标记已读；单条已读、全部已读。

## 9. API 层组织方式

```ts
// api/request.ts — 导出配置好的 axios 实例
import axios from 'axios'

const request = axios.create({
  baseURL: '/api',
  timeout: 15000,
})

request.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token) config.headers.Authorization = `Bearer ${token}`
  return config
})

request.interceptors.response.use(
  response => response.data.code === 200
    ? response.data.data
    : (ElMessage.error(response.data.message), Promise.reject(new Error(response.data.message))),
  error => {
    if (error.response?.status === 401) {
      localStorage.removeItem('token')
      const userStore = useUserStore()
      userStore.token = ''
      userStore.userInfo = null
      router.push('/login')
    }
    return Promise.reject(error)
  }
)

export default request
```

```ts
// api/note.ts — 按模块拆分
import request from './request'

export const getNoteList = (params) => request.get('/notes', { params })
export const getNoteDetail = (id) => request.get(`/notes/${id}`)
export const createNote = (data) => request.post('/notes', data)
export const saveNote = (id, data) => request.put(`/notes/${id}`, data)
export const moveNote = (id, notebookId) => request.put(`/notes/${id}/notebook`, { notebookId })
export const pinNote = (id, pinned) => request.put(`/notes/${id}/pin`, { pinned })
export const deleteNote = (id) => request.delete(`/notes/${id}`)
```

```ts
// api/image.ts — 图片上传（multipart）
export const uploadImage = (file) => {
  const formData = new FormData()
  formData.append('file', file)
  return request.post('/images/upload', formData)
}
```

## 11. 关键约定

1. **Token 存储**：登录/注册后存入 localStorage（key：`token`）
2. **实时保存**：输入即保存（串行队列 + 切走强制落盘），成功后轻提示"已保存"
3. **图片上传**：wangEditor `customUpload` 调 `/api/images/upload`，`base64LimitSize = 0`
4. **导出**：纯前端 Turndown，HTML → Markdown，本地 `.md` 下载
5. **日历**：切换月份调 `GET /api/calendar/marks`；点击日期调 `GET /api/notes?createdDate=xxx`
6. **提醒状态**：进入笔记详情时从 `reminder` 字段读取
7. **未读角标**：登录后拉取一次，之后每 60 秒轮询，卸载时清除定时器
8. **数据隔离**：所有接口后端按当前登录用户隔离，前端无需额外处理
9. **并发约定**：多端同时编辑以最后保存为准（Last-Write-Wins）

## 12. 注意事项

- 尽量使用 Element Plus 自带组件（calendar、dialog、pagination、select、badge），不引入重型第三方库；
- 先集中精力把 **登录 → 笔记列表 → 新建笔记 → 富文本编辑 → 实时保存 → 刷新不丢** 链路跑通，其他模块后续增量添加；
- wangEditor 的 `Editor`/`Toolbar` 需 `v-if="editorRef"` 控制工具栏渲染时机，且工具 key 要用 wangEditor 5 的规范命名；
- 正文为 HTML，凡用 `v-html` 渲染（如列表高亮）都必须先 `escapeHtml` 转义，防止存储型 XSS；
- 后端 Knife4j 文档地址：`http://localhost:8080/swagger-ui.html`，前端开发时直接调后端联调；
- 使用浏览器 Network 面板 + Vue DevTools 调错。
